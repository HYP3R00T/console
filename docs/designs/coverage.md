## Scope and retirement boundary

Production TypeScript/TSX/MJS/CSS, scripts and dependency patches are explicit, including route wrappers; test/support modules, the migration fixture, static mark and checked-in configuration are also mapped.
Generated build/Next output, installed dependencies, local runtime data and ignored configuration are excluded; lockfiles represent resolved inputs without duplicating each dependency here.
Markdown/ASCII documentation, changeset prose and repository governance text are navigated through the documentation/GitHub entry points rather than counted as executable source.
The 74 bootstrap directory READMEs can be removed because their source-bearing interfaces and substantive invariants/effects now live in the linked baselines; empty intermediate route-group documents are replaced by the route table.
This is mechanical file/contract coverage, not proof that all historical rationale is known, every branch is tested or a Goldfish review has approved every consolidated design.
Future source changes must update their owning contract and this index; new consequential behavior additionally needs a focused feature design and appropriate review.
