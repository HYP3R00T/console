# Working rules

- Inspect relevant source and existing changes; preserve unrelated work.
- Follow [development.md](docs/development.md) for tools and verification. Do not bypass checks.
- Read the [Server](docs/packages/server.md) or [Web](docs/packages/web.md) guide when relevant; update it when behavior changes.
- Keep documentation concise, with one source line per paragraph and short bullets.
- Use the primary checkout and one working branch; do not work on `main` or create worktrees without permission.
- Do not restart the owner's development servers without permission.
- Commit, push, merge and publish only when authorized. Use Conventional Commits; committing does not authorize pushing.
