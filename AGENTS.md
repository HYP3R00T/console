# Working rules

- Inspect relevant source and existing changes. Preserve unrelated work.
- Follow [Development](docs/development.md) for tools, verification and documentation maintenance. Do not bypass checks.
- Use the [design sitemap](docs/designs/SITEMAP.md) for feature decisions and inspect the relevant source for current behavior.
- Use the primary checkout and one working branch; do not work on `main` or create worktrees without permission.
- The owner runs the development servers. Ask before starting, stopping or restarting them.
- Commit, push, merge, publish and deploy only when authorized. Permission to commit does not authorize pushing.
